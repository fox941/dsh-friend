## 分工

Mnemon 继续保存用户资料、约定与事实经历。本包管理唯一自我状态、成长提案与审核、版本历史、可恢复的事实纠错、交互规则、增量记忆预演及实际能力快照。通过公开插件接口接入，不修改 DSH 或第三方包源码。预演额外使用已安装 dsh-mnemon-source-runtime 0.5.16 的公开存储格式约定，不增加记忆后端或常驻服务。

根 bundle 提供 friendAdapter 服务，个人 companion 预设加载 /agent 子插件。Setup.ps1 打包后通过官方 CLI 安装。更改源码必须提高包版本，同一版本内容变化会拒绝覆盖。

## 空白自我与成长

初始身份标识是随机 UUID，个人描述、兴趣、特质、个人表达偏好和情绪均为空。主用户直接交流中，模型在有值得留下的新认识时可调用 friend_state_propose；普通聊天不要求每轮变化。

工具冻结本轮主用户原话、事件时间、会话/消息/序号和最近实际对话；每批 1–3 个提案通过一次不带工具的独立模型请求审核。提案与审核分开保存，审核可接受、否决或暂缓。模型路由沿用当前会话，不引入另一个角色或常驻循环。

审核查询当前模型的公开能力元数据；支持 low 推理档时采用 low，控制结构化审核延迟与输出预算，不改变前台聊天的推理档。完成类型、失败诊断与 token 使用会留痕，格式错误或截断不会提交状态。

若审核只缺“她尚未实际说出的选择/反应”，会标记 awaiting_response。程序在本轮实际回答后最多再核对一次，仍用同一用户事件，不增加证据份数，也不需要用户再批准。两次请求都占持久预算；其他原因的暂缓不自动重试。每次审核输入和结果单独留痕，第一次否决不会被第二次结果覆盖。

程序验证身份、逐字引用、版本、依赖、重复内容、事务和预算；模型判断语境、是否同一经历、反例和语义冲突。独立请求仍使用同一个模型，其判断并非客观保证。未通过或格式不正确时保持旧状态，普通聊天可继续。

状态以自然语言为主，不预设名字、情绪标签、恋爱关系、PAD 值、快乐基线或好感公式。interest 至少两条独立事件且跨会话或跨天，trait/self_description/personal_prompt 至少三条，才具备稳定化资格；仍须语义审核。次数门槛不是证据真实性证明。完全相同的事件文本不重复增加支持，改写事件由审核判断；检索、点赞、反思和摘要不加分。

修改含义会重新积累支持。旧认识撤回或改变含义后，依赖它的状态转为 needs_review 并退出当前快照。个人表达偏好必须引用已有非情绪状态，不可循环依赖。个人提示作为有界自我数据影响表达，不能扩大工具、账号或宿主权限。

情绪是当下自然语言描述，可混合、未知或与用户有关的负面感受。默认 180 分钟后不再注入当前状态，历史保留；到期不自动变成某种中性/开心值。

只写有依据的提案。用户喜欢某物不等于 AI 喜欢，角色台词不自动变成人格，只有提案自述也不能证明虚构的现实经历。最近对话仅用于核对实际选择，不算额外独立证据。

## 工具与配置

- friend_state_read：当前版本、状态、有效期与审核额度。
- friend_state_history：过去版本、提案、审核理由、原始依据；可按状态键查询。
- friend_state_propose：set / retract，经审核提交。personal_prompt/self_description/emotion 的键固定为 current；兴趣/特质使用具体主题键。
- friend_memory_read / friend_memory_write / friend_memory_write_retry：日常事实读写与失败续办；friend_memory_history 查询旧事实链。friend_memory_correct 仅保留内部/旧集成兼容，当前陪伴预设不再暴露。
- friend_capabilities：实际渠道、工具、记忆共享与成长状态。

根插件 config.growth 可设置 enabled（默认 true）、dailyReviewLimit（默认 20，范围0–200）、reviewTimeoutMs（默认30000，范围1000–60000）、reviewMaxTokens（默认4096，范围1024–8192）、emotionTtlMinutes（默认180，范围5–1440）。额外调用仅由提案触发；额度以 Asia/Shanghai 日期持久计数，开始的失败/取消尝试也占额度。无提案没有审核调用，不启用夜间任务。

config.writeEnabled=false 同时禁止本包成长与纠错写入。成长状态不依赖独立嵌入服务；Native 纠错遇到尚未验证的 DSH 自定义嵌入路由会停止适配写入。普通 Mnemon 不由本包替代。

## 存储、恢复与迁移

数据为 runtime/<实例>/companion/companion.sqlite，SQLite WAL + FULL 同步。adapter_* 保存纠错过程，growth_* 保存身份、原始依据、提案、审核、当前指针、不可变版本、预算和变更记录。growth_schema 与旧 adapter_schema 分开管理，首次增量创建，不重置旧数据。

成长审核在事务外进行，提交时核验预期版本；并发旧提案只留记录，不覆盖新状态。一次批量提交与依赖失效在同一 SQLite 事务内完成。故障不留下部分自我变化。取消中断审核；重启不会自动再次调用模型，未完成审核标为失败，可在新交流中重试。

事实纠错采用写新并读回、旧值软删除、提交独立日志。Native 与日志库不是一个跨库事务，依赖步骤恢复与精确去重；主动取消的操作暂停自动恢复。新条目保留分类、重要度、标签和实体，旧来源保存在历史中。Native 原有图边不保证在软删除后保留。

完整迁移使用停机后的整个 runtime 实例快照，必须包含 companion、memory、dsh-home 会话/配置/锁文件及 .friend-packages 安装包。单独 Mnemon 导出不包含本包完整状态。迁移目录变化仍须重绑原有绝对路径。

停用根插件后，agent 子插件等待可选服务，原有聊天与 Mnemon 可继续。彻底卸载包前移除 companion 预设里的 friend-interaction 引用，不删除实例数据。

## 验证与边界

成长测试覆盖空白起点、独立证据、重复、跨会话稳定化、含义变化、依赖失效、循环依赖、情绪过期、失败、取消、并发、事务回滚、预算、历史重放、协议和主用户范围。另做独立 DSH 实例中的真实模型验收，避免把测试角色写进真实实例。

当前仅支持已鉴权的本地主用户直接会话，子代理与其他 principal 不开放状态工具；QQ 身份绑定未实现。没有把整个旧会话库自动导入成长证据。管理页/外部 CLI/其他插件的写入不会自动进入本包日志。Runtime 画像与工作记忆仍用 Mnemon 原有替换工具同步，跨来源修改不是一个原子事务。

同义事件识别、反讽、否定、虚构与自我认识质量仍可能误判，程序无法证明语义正确。稳定化门槛、有界快照和小样本测试不等于长期人格质量。已有手动预演和重新审核后的有限提案应用；自动夜间运行、自主活动、独立冷归档和 QQ/B站/抖音尚未实现。

## 增量整理预演

- friend_memory_preview：只在主用户明确请求时预演已完成交流。requestQuote 引用本轮原话；scope=current 默认当前会话，companion 分批处理本实例同一 workspace 下的直接陪伴会话；queries 可提供至多两条相关主题。
- friend_memory_preview_read：读取最近或指定报告；includeSources=true 可核对完整的有界输入。报告本身不能算新增独立证据。
- 通过公开 sessionPersistence 读句柄读取原始事件。只接收本地 companion 预设、固定实例 workspace、未 fork 的顶层会话；其他身份、定时/检索注入、隐藏推理、预演与报告查询回合不作为新经历。
- 仅已结束回合推进预演游标。助手中断内容不作为实际回应；疑似密钥、过长消息和不支持的范围会记录省略原因，不复制敏感正文。USER 是持久资料，不会为模拟降温而清空。
- 常驻资料按公开 JSON 格式读取；Native 使用 --readonly recall，不增加检索计数；查询限本地激活空间，输入、输出与覆盖范围均有上限。Native 只是相关候选，不是全库检查；其他 Providers、自定义 Runtime 路径与 DSH 接管的嵌入路线尚未适配。
- 独立、无工具模型请求提出保留、重复、补充、时间变化、矛盾、工作事项退出常驻候选或自我复核建议。代码核对每个事件 ID、逐字引文和已有条目 ID；每项至少引用一条真实主用户消息。不能只引用助手的总结，也不能引用未读取的记忆。
- 预演只写 preview_* 报告、尝试、预算及扫描进度；不会应用建议、修改 Mnemon 或更新 growth_*。预演工具执行后，该回合阻断其他写入工具并暂停回答后的成长审核；不会撤销预演前已完成的独立写入。
- 默认每日最多 6 次预演模型请求，按上海日期持久计数；失败或取消也计入。无新原始交流不发起审核；报告读取不消耗整理额度。主对话本身的模型调用不包含在这 6 次中。
- config.preview 支持 enabled、dailyCallLimit（0–100）、timeoutMs（1–60秒，默认45秒）、maxTokens（1024–8192，默认4096）、maxSessions（1–12，默认4）、maxTurns（1–24，默认8）、maxSourceChars（2000–30000，默认16000）、maxScannedEvents（128–16384，默认4096）。只读总开关 writeEnabled=false 同时停止新预演日志写入，旧报告仍可读。
- 审核失败、中断、取消、上下文变化或进度并发冲突不会推进预演游标。中断尝试在重启时仅标记，不自动调用模型。预演游标不是将来正式应用记忆的提交游标。
- 新表与旧纠错/成长表隔离，完整实例备份会包含报告。当前没有独立管理页面，通过聊天工具查看。

## 提案应用与跨层复核

- friend_memory_apply：主用户在之后独立回合明确应用报告时使用，传 reportId、逐字 requestQuote，可选 proposalIndexes。不逐项另弹审批；程序重新核对原始交流、现有目标和本轮具体授权。
- friend_memory_apply_read：查询应用回执、原话、分步结果、待处理原因，并核对已应用目标是否仍为当前值。历史完成不会重放成当前事实。
- keep/duplicate 无需写入，conflict/defer、未来才生效或语义不清的提案保留待定。其他提案经一次独立无工具应用审核变成有限操作，支持常驻新增/替换、Native 经历新增/事实更正、普通工作记忆完整转存以及自我状态标为待复核。
- 常驻写入复用 Runtime Source 公开 factory/manage 接口。普通 mutate 没有 CAS，本包使用有版本核验的 compact-and-mutate，保留全部其他条目，不自行压缩或删减。容量不足、来源元数据未适配等情况停留在待处理，不能为写入新值而丢弃旧资料。
- Native 更正沿用已有可恢复纠错流程，旧版本与依据保存在历史。转存先完整写入并读回 Native，再在受控锁内核对并移出普通 MEMORY；USER 与 critical 约定不能据此转存。没有增加独立冷库，也不物理删除原始经历。
- 已知完全相同的旧副本须同步更正；审核还可标记语义相关自我认识待复核，递归暂停已有个人提示依赖。原支持数不增加，不产生新性格。关系由本次审核建立并记录；未识别、未声明的关联不保证完整传播，管理页/外部 CLI/其他插件的写入尚未统一捕捉。
- 事实步骤有已写或结果未知而相关状态复核未完成时，该状态及依赖暂时退出当前自我上下文，等待核对。新的主用户交流形成的新版本不会被旧应用计划覆盖。
- apply_* 表保存授权、审核、固定计划、每步意图、回执、预算与关联。中断后不自动再次调用审核模型；再次明确应用相同报告/序号，优先核对和继续原计划。回执不明且数据已有变化时停止，不能盲目新增；Native 的精确核对与 oplog 序号读取只用于锁定版本的恢复判断，不替代检索引擎。
- completed 表示所选项核对完成，partial/cancelled/interrupted 可能已有部分写入；applied=null 表示有结果尚待核对，不能解释为完全未写入。后来改过的完成记录显示 historical，不恢复旧值。跨库不是原子事务，也不承诺通用 exactly-once。
- config.application 支持 enabled（默认 true）、dailyCallLimit（默认6，0–100）、timeoutMs（默认60000，1000–60000）、maxTokens（默认8192，1024–8192）。无动作项不请求应用审核，失败/取消计入当日额度；重放固定计划不额外审核。writeEnabled=false 禁止新应用，历史仍可读。
- 应用工具执行后本回合只允许读取和报告，暂停回答后的成长审核。预演工具仍然只读；其报告查询现在会附带后续应用状态，不能只看原摘要判断是否已经修改。

## 整理批次保护

0.6.0 在提案应用写入前保存相关 Native 全库（含图）、Runtime 及 companion 一致性快照，失败则 backup_blocked，不转用其他工具代写。0.8.0 已接陪伴日常写入；外部 CLI、管理页和其他预设未全局接管。无写入步骤不生成快照。

friend_memory_changes 可查看旧值、新值、原话、自我影响、回执和静态 HTML，并预检停机撤销。撤销入口是项目离线命令；Native 恢复前比较全库指纹，有任何后续变化就保守拒绝。Runtime 只撤销本批目标，保留无关新条目；自我状态有后续变化则停止。旧批次没有前置快照，不能补造完整撤销保证。默认保留最多16份、合计512 MiB，过期仅删除受控快照，不清理事实和会话。

项目命令 Stop-Dev.cmd → Undo-Memory.cmd 应用批次UUID → 成功后 Start-Dev.cmd。离线维护占用宿主启动锁，逐步意图与回执持久化；撤销部分完成或中断时宿主拒绝启动，按同一批次重试。Native 访问计数和图变化也会改变指纹，可能保守拒绝恢复。撤销先保存现态副本，自我恢复生成新版本且沿用原支持，不回滚整个 companion 数据库，不删除原始聊天或审核日志。此功能保护工程性误改，不判断模型提案的语义真伪，不承诺跨库原子事务。
