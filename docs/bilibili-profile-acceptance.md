# B站人物画像真实验收与宿主装配修复

日期：2026-11-02；修复版本：companion-adapter 0.43.4。B站插件仍为0.4.8，QQ桥接0.11.2，调度器0.2.0。

## 验收前发现的问题

独立账号1846088125仍能通过实际登录核验，绑定的主用户UID为353223108；但私信、@和回复的持久轮询时间没有前进。这说明“账号在线”和“配置启用”不能证明接收器实际运行。

拆分后的B站宿主从 `ports.review.reviewStructured` 读取共享结构化审核器，而宿主组合根只提供了平铺的 `ports.reviewStructured`。接收、社交和观看宿主在装配阶段无法正常绑定，因此没有创建正常轮询循环。已有模块单元测试主要手工绑定测试宿主，未覆盖这一真实组合边界。

## 修复

- 在companion-adapter组合根补齐 `review:{reviewStructured}`；保留原平铺接口的兼容性。它指向同一个已有函数，没有增加模型角色、供应商或记忆副本。
- 只读运行状态新增 `bilibili.inboxHostReady`、`socialHostReady`、`activityHostReady`、`lastPollAt`，区分登录状态与宿主装配状态。最近轮询时间不代表已有新消息，更不代表已回复。
- 新增真实Cordis四插件装配测试，禁用平台通道及模型调用，验证实际组合根创建的三个B站控制器均绑定宿主。原代码在同一夹具下失败，修复后通过。
- 保留原通知游标、消息原件、发送回执、账号绑定及记忆，不手工注入消息、重投旧事件或把平台回执直接改成成功。

## 本轮真实验收顺序

1. 核对实际AI账号、主UID、四插件源文件/安装包一致性。
2. 部署后确认三个宿主就绪，私信、@、回复的轮询时间实际前进。
3. 主用户通过B站私信陈述一条真实且愿意长期保存的新偏好，明确允许记住。不要使用“接入测试/不保存记忆”，这些词会禁止学习。
4. 核对平台原消息、模型提案、独立审核、Native实际写入与索引、画像描述、常驻筛选、页面来源。模型可以不回应、暂缓或否决写入；不为了通过验收强制改写决定。
5. 用户从QQ私聊询问该偏好，不在问题中重复答案。区分已有会话上下文命中、统一人物画像和Native召回证据。
6. 更正或撤回需要新的真实原话，检查旧值不会继续作为当前事实；不为测试植入虚假偏好。
7. 私聊来源没有公开授权时不得进入公开画像投影。优先做隔离负向验证；如需真实公开提交，提前明确实际评论位置和提交内容。

## 存储与边界

B站原事件位于 `companion.sqlite` 的 `bili_inbox_events`，话题和审核决定在 `bili_social_*`；已应用的长期原文在原Native空间，索引引用真实应用批次。主用户通用画像由已绑定账号读取这些原记录，不按昵称合并他人身份。

只有带有通过审核的profile描述且Native当前内容仍匹配的B站事实，才进入统一画像。常驻USER摘要沿用上一版本的受保护维护流程；不是每条社交经历都会进入USER。私人事实进入主用户私聊摘要不等于获得公开许可。

本轮隔离回归1380项、安装包回归583项；真实场景分阶段核验，未完成部分不能标记通过。进度和实际证据以 `.work/bili-profile-acceptance-acceptance.json` 为准。

## 本轮实际结果

修复部署后三个宿主均就绪，私信、@和回复游标的轮询时间已实际前进。主用户通过B站私信给出一条真实游戏偏好；原消息进入模型提案、独立审核、受保护应用和Native索引。独立只读CLI核验原文与索引哈希一致。随后自动维护器将其选入USER摘要，页面显示B站私信来源、人物范围、保留来源披露边界及维护状态。

主QQ的自然提问未包含游戏名，模型正确回答了B站提供的偏好。真实会话原件中，对应B站画像出现在首次回答之前；正常QQ出站回执成功，用户确认B站和QQ两端均可见。该轮QQ提问没有新增日常记忆应用。真实偏好正文和原会话证据保存在本机`.work`验收资料，不复制进本说明。

使用真实已审核原件的只读过滤验证确认：同一主用户QQ私聊可使用该条目，QQ群、B站公开场景和其他好友不可得到该条私信画像。更正/撤回检查通过内存隔离读视图模拟Native版本变化与来源撤回，旧投影失效；没有实际修改、撤回或删除用户的真实偏好，也没有为验收发公开评论。

这一轮验证了现有原件更正/撤回后的失效保护；没有新增“B站普通私信的自然语言更正自动定位并替代旧画像”的入口。新的独立陈述仍可能作为新经历保存，不能把本轮结果理解成任意偏好变化都已能自动合并、覆盖。

用户随后反馈另一轮等待后已收到回复，并明确取消该次延迟排查；本轮没有继续读取该轮内容或尝试重发。
