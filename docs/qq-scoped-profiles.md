# QQ 群与空间中的画像更正和撤回

版本：companion-adapter 0.46.0、qq-bridge 0.12.0。沿用 DSH、Mnemon Native、统一人物画像、受保护应用和行为调度，不新增记忆引擎或后台进程。

## 使用方式

必须由绑定的主 QQ 账号发出新的真实原话，并正常进入已接入的群或 AI 自己说说的评论收件。普通群友无法通过“我是主人”等文字获得身份。

| 原话举例 | 生效范围 |
| --- | --- |
| “本群以后改叫我小树。” | 当前群，不改变私聊或其他群的通用称呼 |
| “撤回在本群使用北风这个称呼。” | 仅停止本群的旧用法，其他场景仍保留原通用约定 |
| “这个评论区以后改叫我小树。” | 该条说说，不扩展到相同可见范围的其他说说 |
| “更正我的通用称呼，以后叫我云杉。” | 同一主用户的通用画像，同步精确关联的常驻摘要 |
| “这次临时叫我小树。” | 不形成永久画像更正 |

公开来源默认局部，明确表达“通用、全局、所有平台”等意图才进入通用更正；同时带有本群、这里等局部限定时不扩大范围。引用、假设、玩笑、补充另一种兴趣或语义不明确，可以被模型否决或暂缓。入口识别不是模型批准，提案也不等于提交成功。

尚无对应可见旧画像的首次偏好仍走原社交记忆新增流程；本功能负责已有画像的时间关系。旧全局偏好不能因一次临时聊天自动恢复。

## 职责与执行路径

```text
QQ 原始收件（群 / 空间评论）
  → 账号、原话、处理状态、学习许可核验
  → 已有画像更正交接，避免旧社交模块重复写入
  → ProfileChanges 收集来源、按范围选择旧事实
  → 模型提案 → 宿主编译固定操作 → 独立模型审核
  → 提交前再次核验来源与版本 → 一致性快照
  → Native / Runtime 逐步写入与回执 → 当前版本关系
  → PersonProfiles 按实际目标场景提供只读画像
```

局部变更可基于原场景记录，也可基于该场景已经可见的通用事实。后者创建独立的场景覆盖，不改写全局原件或 USER 摘要。场景覆盖会抑制当地旧通用用法；后来全局更新仍保留既有局部例外。

通用更正只处理同一主用户的通用目标，保留无关偏好和已有局部约定。是否理解为更正、撤回或只是补充，由提案和独立审核判断；固定计划和写入范围由宿主控制。恢复已撤回偏好必须有新的真实原话。

## 隐私与原话核验

- 局部提案与审核只接收本场景可见的候选，不读取私人 USER 内容。
- 公开来源明确更正通用偏好时，内部审核可核对本人的私密旧值；公开聊天只收到经过范围过滤的新事实，不附旧值、审核原因或私人 Runtime。
- 适用范围与公开许可分开：通用不意味着可以公开其他私人资料。新公开来源原件仅记录新原话、新事实和范围等元数据，不复制隐藏旧值。
- 空间更正提交前在线核验原帖作者、可见范围和评论正文。正文编辑、范围变化等会阻止提交；网络不可核验时保留待处理，不回退为历史原话写入。
- 禁止保存、本轮测试、历史恢复消息、他人身份和撤回来源不能生成新的主用户画像变更。

## 数据与迁移

继续存放在 `runtime/dev/companion/companion.sqlite`：`platform_events` 是原始社交收件，`qq_social_*` 保留原社交记忆，`profile_change_*` 保存提案、版本、局部覆盖关系和撤销回执。Native 保存受保护的变更原件；通用常驻摘要仍由 `memory/runtime/memories.json` 管理并生成 USER.md。

本版本不新增数据库表，仅给现有 `profile_change_meta` 增加 `qq-social-cutoff` 启用基线。首次启用不补处理旧群聊或空间评论。局部覆盖不是第二份通用用户画像；旧社交条目的物理 active 状态也不代表它仍是当前用法，应通过统一画像读取器查看。

迁移继续使用现有整实例迁移工具，包含插件固定版本、完整 runtime 和 Native 数据，不能只复制某个插件目录。已有受保护批次撤销继续使用版本核验：后续改动可能导致保守拒绝撤销，不覆盖新数据。

## 本次边界

本功能只扩展绑定主用户的 QQ 群及自己空间评论；B站公开评论的画像更正未纳入本次。其他好友继续使用各自的社交记忆。

QQ 公共场景的完成结果可在已认证的“人物画像 → 更正与撤回”查看，后续聊天可读取当前用法。本次未接入公共场景的自动完成回报，也不会把群/空间更正私下转发到主 QQ。即时回复不能替代后台完成回执，AI 的自主关注与暂缓仍由统一调度决定。

不因本次升级修改真实偏好或补发旧消息。真实群/空间更正与手机可见性需等待用户愿意实际更正的自然场景验收，隔离测试不能替代真人验收。
