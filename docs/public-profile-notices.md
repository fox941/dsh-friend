# 群聊与QQ空间的画像更正结果回报

companion-adapter 0.47.0。扩展现有 ProfileNotices、统一注意力和QQ平台客户端；不增加数据库表、第二套人格或独立决策循环。

## 行为

绑定主用户在已接入群或AI自己说说的评论中提出画像更正后，经过核验的完成、暂缓、否决、部分完成或备份受阻结果可以形成回报候选。统一注意力先选择是否关注，再由同一模型选择告知、暂缓或沉默，正文经过独立出站审核。后台完成不保证她立即通知，也不强制回复。

回到原群时引用原消息并提及原主用户；空间回复固定到原说说、原评论作者与准确楼层。不会转发到主用户私聊，不新建虚假收件，不将结果回报写成新的记忆、情绪或共同经历。

## 公开数据边界

表达与出站审核只获得本次公开请求、已核验的新事实、适用范围和执行状态，不传旧值、内部理由、失败详情、私人Runtime或完整自我状态。未完成结果不提供尚未经批准的新事实。局部更正不能宣称其他群、私聊或所有平台都改变了。

原群和原帖后续聊天可以只读查看此前已确认发送或原页已观察到的回报，其他话题不加载。已明确告知过的同一结果交模型判断是否需要再次说明；独立发送回执负责防止重复提交。

## 原件、发送与恢复

- 生成前及提交前重核验来源、账号、群接入范围、群成员关系、空间可见范围与评论内容；新消息、自我状态或目标变化后废弃旧稿，待重新选择。
- 空间沿用QQ客户端的 prepare/write/verify 和 platform_operations 台账。通知专属准备状态不进入普通平台发送队列；重启遗留的未提交旧稿也不能被平台协调器独立发送。
- 群发送取得OneBot消息ID才能记为 sent。未知结果保留 unknown，不自动重发。
- 空间仅受理记为 unconfirmed；原评论下读到作者、目标和正文匹配的回复，记为 observed。页面观察不能证明API评论ID归属、对方可见或已读，不记为“对方已收到”。
- 复用已有每日空间操作额度；暂停、取消和本话题后续停止通知要求继续有效。首次升级不补推已记录的历史结果。

数据仍在 companion.sqlite 的 profile_notice_* 和 platform_operations 中，完整实例迁移会携带。原QQ、B站私聊回报沿用原入口。B站公开评论回报不在本次范围。

## 验收边界

隔离夹具与真实模型验证不等于真实平台送达。真人群/空间更正以及手机可见性，留待用户确实愿意更改的自然偏好场景；不为测试修改真实人物画像或补发旧请求。
