# 陪伴运行适配 0.2.3

固定组合：DSH 0.2.1-rc.3、dsh-mnemon 0.5.36、Native 0.2.13、Node 24.22.1。JavaScript ES Modules，直接运行，不增加模型服务、向量库或新的第三方运行依赖。

## 分工

Mnemon 继续保存用户资料、约定与事实经历。本包管理唯一自我状态、成长提案与审核、版本历史、可恢复的事实纠错、交互规则及实际能力快照。通过公开插件接口接入，不修改 DSH 或第三方包源码。

根 bundle 提供 friendAdapter 服务，个人 companion 预设加载 /agent 子插件。Setup.ps1 打包后通过官方 CLI 安装。更改源码必须提高包版本，同一版本内容变化会拒绝覆盖。

## 空白自我与成长

初始身份标识是随机 UUID，个人描述、兴趣、特质、个人表达偏好和情绪均为空。主用户直接交流中，模型在有值得留下的新认识时可调用 friend_state_propose；普通聊天不要求每轮变化。

工具冻结本轮主用户原话、事件时间、会话/消息/序号和最近实际对话；每批 1–3 个提案通过一次不带工具的独立模型请求审核。提案与审核分开保存，审核可接受、否决或暂缓。模型路由沿用当前会话，不引入另一个角色或常驻循环。

审核查询当前模型的公开能力元数据；支持 low 推理档时采用 low，控制结构化审核延迟与输出预算，不改变前台聊天的推理档。完成类型、失败诊断与 token 使用会留痕，格式错误或截断不会提交状态。

若审核只缺“她尚未实际说出的选择/反应”，会标记 awaiting_response。程序在本轮实际回答后最多再核对一次，仍用同一用户事件，不增加证据份数，也不需要用户再批准。两次请求都占持久预算；其他原因的暂缓不自动重试。每次审核输入和结果单独留痕，第一次否决不会被第二次结果覆盖。

程序验证身份、逐字引用、版本、依赖、重复内容、事务和预算；模型判断语境、是否同一经历、反例和语义冲突。独立请求仍使用同一个模型，其判断并非客观保证。未通过或格式不正确时保持旧状态，普通聊天可继续。

状态以自然语言为主，不预设名字、情绪标签、恋爱关系、PAD 值、快乐基线或好感公式。interest 至少两条独立事件且跨会话或跨天，trait/self_description/personal_prompt 至少三条，才具备稳定化资格；仍须语义审核。次数门槛不是证据真实性证明。完全相同的事件文本不重复增加支持，改写事件由审核判断；检索、点赞、反思和摘要不加分。

修改含义会重新积累支持。旧认识撤回或改变含义后，依赖它的状态转为 needs_review 并退出当前快照。个人表达偏好必须引用已有非情绪状态，不可循环依赖。个人提示作为有界自我数据影响表达，不能扩大工具、账号或宿主权限。

情绪是当下自然语言描述，可混合、未知或与用户有关的负面感受。默认 180 分钟后不再注入当前状态，历史保留；到期不自动变成某种中性/开心值。

只写有依据的提案。用户喜欢某物不等于 AI 喜欢，角色台词不自动变成人格，只有提案自述也不能证明虚构的现实经历。最近对话仅用于核对实际选择，不算额外独立证据。

## 工具与配置

- friend_state_read：当前版本、状态、有效期与审核额度。
- friend_state_history：过去版本、提案、审核理由、原始依据；可按状态键查询。
- friend_state_propose：set / retract，经审核提交。personal_prompt/self_description/emotion 的键固定为 current；兴趣/特质使用具体主题键。
- friend_memory_correct / friend_memory_history：Mnemon Native 当前事实纠错与历史。
- friend_capabilities：实际渠道、工具、记忆共享与成长状态。

根插件 config.growth 可设置 enabled（默认 true）、dailyReviewLimit（默认 20，范围0–200）、reviewTimeoutMs（默认30000，范围1000–60000）、reviewMaxTokens（默认4096，范围1024–8192）、emotionTtlMinutes（默认180，范围5–1440）。额外调用仅由提案触发；额度以 Asia/Shanghai 日期持久计数，开始的失败/取消尝试也占额度。无提案没有审核调用，不启用夜间任务。

config.writeEnabled=false 同时禁止本包成长与纠错写入。成长状态不依赖独立嵌入服务；Native 纠错遇到尚未验证的 DSH 自定义嵌入路由会停止适配写入。普通 Mnemon 不由本包替代。

## 存储、恢复与迁移

数据为 runtime/<实例>/companion/companion.sqlite，SQLite WAL + FULL 同步。adapter_* 保存纠错过程，growth_* 保存身份、原始依据、提案、审核、当前指针、不可变版本、预算和变更记录。growth_schema 与旧 adapter_schema 分开管理，首次增量创建，不重置旧数据。

成长审核在事务外进行，提交时核验预期版本；并发旧提案只留记录，不覆盖新状态。一次批量提交与依赖失效在同一 SQLite 事务内完成。故障不留下部分自我变化。取消中断审核；重启不会自动再次调用模型，未完成审核标为失败，可在新交流中重试。

事实纠错采用写新并读回、旧值软删除、提交独立日志。Native 与日志库不是一个跨库事务，依赖步骤恢复与精确去重；主动取消的操作暂停自动恢复。新条目保留分类、重要度、标签和实体，旧来源保存在历史中。Native 原有图边不保证在软删除后保留。

完整迁移使用停机后的整个 runtime 实例快照，必须包含 companion、memory、dsh-home 会话/配置/锁文件及 .friend-packages 安装包。单独 Mnemon 导出不包含本包完整状态。迁移目录变化仍须重绑原有绝对路径。

停用根插件后，agent 子插件等待可选服务，原有聊天与 Mnemon 可继续。彻底卸载包前移除 companion 预设里的 friend-interaction 引用，不删除实例数据。

## 验证与边界

成长测试覆盖空白起点、独立证据、重复、跨会话稳定化、含义变化、依赖失效、循环依赖、情绪过期、失败、取消、并发、事务回滚、预算、历史重放、协议和主用户范围。另做独立 DSH 实例中的真实模型验收，避免把测试角色写进真实实例。

当前仅支持已鉴权的本地主用户直接会话，子代理与其他 principal 不开放状态工具；QQ 身份绑定未实现。没有把整个旧会话库自动导入成长证据。管理页/外部 CLI/其他插件的写入不会自动进入本包日志。Runtime 画像与工作记忆仍用 Mnemon 原有替换工具同步，跨来源修改不是一个原子事务。

同义事件识别、反讽、否定、虚构与自我认识质量仍可能误判，程序无法证明语义正确。稳定化门槛、有界快照和小样本测试不等于长期人格质量。夜间整理已复用现有事实更正与状态复核；自主活动、独立冷归档和 QQ/B站/抖音尚未实现。
