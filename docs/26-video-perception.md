# B站分段视频感知

2026-10-29；companion-adapter 0.19.1；架构 v0.21。视频平台后续仅规划 B站，抖音暂不接入。

## 行为与模块

继续使用统一注意力、当前 DeepSeek 模型和同一套人格、情绪、记忆。主用户仍通过 friend_bilibili_explore 进入，后台仍由 browse 活动进入；没有同时暴露多个 B站提取插件。读取视频不会自动点赞、评论、关注或发送 QQ；已有社交和主动联系另走原流程。

1. VideoMedia 使用现有 B站认证/限流客户端核验 AI 账号、BVID、分P与 CID，获取官方媒体流。凭据只发送官方 API，不发送 CDN、Python 或模型；临时签名媒体地址不进回执。
2. 同一角色的 watch 决策根据实际状态和观察进度选择片段、缩小区间补看、继续或停止。窗口长度和次数只是资源上限，没有必须看完、必须回复或固定兴趣。
3. 字幕按区间优先获取；确认 SUBTITLE_UNAVAILABLE 时才本地转写。认证、限流等错误不会伪装成无字幕。ASR 先下载受限音频，再只裁出选定窗口进行推理。
4. 在选定区间做 FFmpeg 场景检测和均匀补采样，提取有限图片，记录实际解码 PTS、目标时间、图像 SHA256 和 DSH 附件引用。场景检测失败可以降级均匀采样。
5. 图片通过公开附件服务与 llm.stream 送给当前模型。vision 只做有边界的画面解读，返回内容明确标为模型推断；之后原 reflect / memory / growth / emotion 继续独立处理，可无变化或拒绝保存。

## 默认资源边界

每次活动最多两个窗口，每窗口最多 60 秒、4 张图片；整个活动最多 12 次模型请求，默认执行时间预算 300 秒。可在插件 video 配置中调整 windowSeconds、maxWindows、maxFrames 和 evidenceLimitBytes；活动 timeoutMs 沿用 activities 设置。

视频流在 64 MiB 内时可本地下载；已知整片大小超过上限时改用受限 HTTP Range 读取。FFmpeg 通过会话内随机路径的本机临时接口按需定位，接口只转发经过白名单校验的 B站 CDN，不传 QQ/B站 Cookie，也不把签名地址交给子进程。单会话分段累计读取上限仍为 64 MiB、最多96次请求，至多4个并发读取，支持取消且任务结束即关闭临时服务；不会为了长视频放开整片下载。音频当前仍为整条下载最多24 MiB，再裁出窗口；图片长边约束768像素。图片获取或解读失败时，保留实际成功的文字并记下未完成范围及明确的媒体/解码/附件/模型失败阶段；文字与画面都未成功则该片段失败。

原始视频、音频和工作图片存于 runtime/dev/cache/video/capture-*，正常完成、失败、取消均清理；下次打开活动时仅清理本目录内超过30分钟的旧 capture-* 实目录，拒绝跟随链接。硬退出可能短暂留下缓存。

模型请求所用的有据图片通过 DSH 附件服务保存，位于 runtime/dev/dsh-home/attachments；图片索引按内容去重。视频附件累计预算默认 256 MiB，达到预算暂停新增图片，保留旧证据和记忆，不自动删除历史附件。原始媒体缓存与持久附件是不同的东西。

## 来源与持久状态

companion.sqlite 新增 activity_video_sessions、activity_video_segments、activity_video_frames 三张表。保存模型片段计划、已完成片段、进度、源类型、图像引用和大小。已有表和角色身份不重建。

最终观察仍进入 activity_observations，但以分P、CID、实际区间、语言来源正文与原始帧哈希去重。模型把相同原件换一种描述不会产生新的独立经历。旧版字幕原件保留；新观察独立带有 multimodal 协议和范围，不能将旧记录改成新看过的画面。

字幕是平台文字，可能包含与所选区间相交的整句边界上下文。ASR 文字和时间由模型估计，可能错字；抽样画面描述是模型推断，不是字幕，也不能证明帧间连续动作、语气、音乐或作者观点真实。每一份观察保留这些边界。静音视频可以仅根据画面观察，不编造语言。

阶段完成后先持久化片段再继续选择，取消/重启能复用实际取得的片段。已有活动暂停检查点继续生效；正在运行的媒体进程受取消信号与超时控制。learn=false 仍保留观察和操作回执，但不写 Mnemon、兴趣或情绪；不产生主动联系来源。

## 安装、查看与迁移

- 首次或迁移路径改变后运行 Setup-Video.cmd，安装/重新核验项目专用媒体环境；不改系统环境。依赖脚本允许继承现有代理，但不继承账号密钥。ASR 依赖锁见 scripts/video-requirements.lock.txt。
- Video-Status.cmd 查看本机工具、自检状态、实际片段和图片证据占用；friend_activity_status 也显示活动资源设置。
- 可执行环境与权重位于 .tools/video，是可重新安装的依赖，不是人格。固定模型版本与来源记录随工具清单保存。
- 迁移身份和记忆时，停机完整迁移 runtime/dev，并保留匹配插件代码/发布工件。视频证据包括 companion.sqlite 和 dsh-home/attachments，不能只复制 mnemon.db。媒体原始缓存可不迁移。
- 可复制 .tools/video 复用同平台权重；Python venv 含基础解释器路径，目标路径改变时运行 Setup-Video.cmd 重新创建环境并自检。不要把“复制 venv”当作跨路径必然可用。
