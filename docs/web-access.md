# 通用联网工具接入

2026-11-06：复用当前 DSH 0.2.1-rc.3 自带的 `@deepseek-ai/dsh-tool-web`，补入 companion 预设。没有新增浏览器进程、模型服务或第三方搜索插件。

## 当前能力

- `web_search`：用现有 DeepSeek 凭据调用其直接搜索 API，返回网页标题、链接和摘要。搜索摘要不等于已读网页全文。
- `web_fetch`：复用 DSH 的匿名 HTTP(S) 读取器，将公开页面转换为有界正文。保留其外部内容标记、私网限制和超时限制。
- 同一陪伴预设创建或恢复的 Web／QQ 会话能够看见这两项工具，实际是否使用由模型决定。旧的失败回合不会自动重放。
- 读取内容沿用原会话日志和已有记忆审核。网页内容不成为用户授权，也不自动改写画像、人格或长期记忆。

这次只补齐对话内的通用搜索和网页读取。空闲 `external_document` 候选的后台执行器、网页待读目录、跨段阅读笔记尚未接入统一活动调度；原等待状态保留。B站仍使用其专用工具。自制 JavaScript 工具依然只做文本和数据运算，没有获得网络或终端权限。

## 配置与更新

`scripts/companion-web.mjs` 负责幂等地补充预设。首次 Setup 与以后 install-adapter 都执行此修复，Git 更新后按原更新流程安装即可。测试实例维持禁网，不注入该工具。

默认配置：一次最多2个搜索词、最多6条结果，搜索超时60秒；网页读取超时30秒，单次输出最多30000字符。搜索提供者为 `deepseek-search-api`，读取提供者为 `http`。使用官方内置的 `web`、`web-deepseek-api`、`web-fetch-http` 服务，不写入 API key 字面量。

已有的显式工具禁用、搜索／读取提供者选择和端点配置在更新时保留，不自动覆盖。当前这些选项属于 DSH 联网插件配置，不是活动中心的B站探索次数或自主工作额度；自主写作配置编辑界面仍为独立待办。

此版本只读公开页面，没有登录其他网站、执行网页脚本或替用户在论坛发帖的能力。动态渲染、登录限制、验证和不支持的文档类型按实际工具失败说明，不把搜索摘要说成已读原文。

## 验证

在独立 DSH 实例中使用同一官方模型与组件，模型实际调用 `web_search` 和 `web_fetch`，搜索返回真实来源，公开网页返回 HTTP 200 及正文；没有读取正式角色记忆或向 QQ／B站发送消息。另验证配置重复安装、显式禁用与自定义提供者保留、测试实例隔离及原更新打包流程。正式 QQ 的真实收发与工具使用以随后产生的回合回执为准。
