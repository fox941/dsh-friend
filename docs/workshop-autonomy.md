# 空闲自主写作与工具制作

版本：companion-adapter 0.78.1，activity-console 0.3.1。复用原统一注意力与工作间，不新增调度循环或另一套人格。

## 活动怎样产生

原有空闲机会、当前自我兴趣、长期目标及未完事项进入同一次行为选择。模型可以在 suggestions 中提出 kind=workshop 的作品目标，也可以继续看视频、聊天、回忆、反思或安静。新任务只进入原队列，不立即执行。候选生成阶段没有默认题目、固定文体或“每天必须创作”的要求。

已存在任务呈现在 workshopState.tasks。相同作品引用真实 intentId 和 version 复用；没有进度的任务可补充关注点，已有进度不重写目标。相同题目的终态事项不因重复提案而复活。不把作品合并机制套到聊天或对外发送。

主用户也可用 friend_workshop_task_propose 提出后台任务，须引用本轮真实原话。主用户 Web／QQ 可通过 friend_workshop_task_read 查看进度，或用 friend_workshop_task_control 暂停、恢复、取消未结束任务。控制要求刚读到的版本及本轮明确原话；普通好友、群消息和公开评论没有这组入口。

## 每次只推进一步

统一注意力选中后，模型只决定一个步骤：读取工作文件、只读回忆旧经历、写稿、定义工具、试跑、注册、调用、完成、暂缓或放弃。实际操作复用原工作间 API 和 QuickJS 隔离引擎。写文件仍核对旧版本，工具仍须先测试成功再注册。

一步取得回执后，保存检查点、释放执行，再由原注意力决定接下来做什么。步骤间默认至少60秒，实际继续时间取决于模型、资源和其他活动。尚未到安全切换点时，其他任务等待该步骤结束；没有机械聊天优先级。模型选择 wait 或 abandon 原样保留，资源等待单独标记。

“等状态变化”使用专属唤醒条件：自身状态、目标或工具状态变化才重新考虑。保存本任务进度不算这种变化，避免自己唤醒自己。等待其他任务结束也不会被本步骤自己的结束信号立即唤醒。

完成必须引用本任务已有的文件或已注册工具，并检查当前版本。读取、检索、试跑或“打算写”不能作为作品完成依据。工具失败、部分文件提交和中断按真实回执展示。先保存固定步骤再执行；重启核对原文件、测试和注册回执，不重新请求旧模型步骤或盲目重复执行。

## 每日资源

| 资源 | 默认上限 | 计数方式 |
|---|---:|---|
| 当天投入的不同自主工作任务 | 6个／日 | 第一次执行该任务占一个名额；续做旧任务也占当天名额，同任务当天不重复计数 |
| 自主工作模型步骤 | 24次／日 | 请求模型前预留；失败、暂缓和完成判断也计数 |
| 脚本试跑／正式执行 | 128次／日 | 沿用原工作间额度；每个测试用例和每次运行分别计数 |

按北京时间自然日保存记录。耗尽后保留进度，次日只重新开放选择机会，不自动执行。以上均为上限，不是任务指标，与B站探索、夜间整理及成长审核分别计账。

活动中心的「资源与异常」显示三组实际用量；「待办与执行」显示“写作与工具制作”，详情可查看已推进步数、真实成果路径与版本。刷新只读，不唤醒任务或调用模型。首版未新增数值编辑表单；可在 friend-adapter.config.workshopAutonomy 配置 enabled、maxTasksPerDay、maxStepsPerDay、maxOpen、stepCooldownSeconds，配置变动需要按原插件重载流程生效。

## 记忆、隐私和真实经历

观后感等事实性写作可通过原记忆读取器只读回忆；候选并不等于本轮逐字核对通过，未找到的内容应标为未知、写成虚构或暂缓。回忆结果不能作为新外部事实或人格支持再次强化。

作品仍是 workshop/files 中的文件。自主工作没有记忆、人格、情绪写入或平台发送接口；完成不会自动向QQ、B站或其他人发布。主用户聊天中的原记忆与自我审核入口继续使用。第一版不提供通用终端、联网脚本或安装宿主插件的权限。

## 存储与迁移

- 文件、工具、测试和执行回执：原 runtime/dev/workshop。
- 任务与进度：原 companion.sqlite 的 attention_checkpoints，workshop-task:*。
- 每日额度与状态版本：同表的 workshop-control:v1。
- 活动选择与等待：原 attention_intents、attention_decisions 等记录。

没有新增数据库或修改表结构。完整迁移须带原 companion.sqlite 和 workshop，单独复制文件目录不能恢复完整任务进度。空白部署仍从空身份、空记忆和空工作间开始。恢复异常仅暂停自主工作能力，保留原检查点，其他陪伴能力继续可用。

## 验证范围

最终安装包已运行自主工作、原工作间、统一选择、复用、记忆、运行保护、活动中心权限及更新打包回归。独立 DeepSeek 场景完成短文保存和工具定义、两个用例测试、注册、实际调用、结果文件与完成核验：2个任务、9个模型步骤、4次脚本执行。调度选择为受控夹具，不是自然兴趣或长期行为质量基准；没有向正式角色植入作品、工具或提案，没有发送QQ／B站消息或读取正式记忆。

真实 DSH 启动与正式部署分别记录在 .work/workshop-autonomy-release.json；正式角色长期是否喜欢创作、产出频率是否合适，继续在正常使用中观察，不为验收强迫她创作。
