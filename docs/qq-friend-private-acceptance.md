# 其他 QQ 好友私聊与社交记忆验收

本次补正：companion-adapter 0.34.5、qq-bridge 0.3.6。B站插件不在修改范围。

其他好友私聊沿用 `qq-private:<AI QQ>:<发送者 QQ>`，一个好友一个持久话题，保留原始消息、已实际发送的回复和独立社交长期记忆。它使用当前角色的公开性格、兴趣和感受；不是主用户完整工具会话。群聊话题另行隔离。QQ 昵称相同不合并人，身份由真实发送账号决定。

本次发现并补正的缺口：好友消息收件后排队，好友聊天设置或好友关系可能在等待、媒体读取、记忆检索、模型表达期间改变。处理前检查当前好友关系；上下文准备及模型返回后检查来源、绑定和设置；发送前再次检查当前好友关系。停用好友聊天、删除好友或将该账号改为主用户后，旧社交候选取消，不转入主用户私聊，不提交旧稿或该稿记忆。连接暂未核验时等恢复事件，好友列表读取失败或格式异常时三十秒后重新考虑，不把查询失败当删除好友。

检查只决定当前工作是否仍有效，不决定角色应该回复、暂缓还是忽略。重新考虑时重新生成表达，不定时发送旧稿。没有新增模型调用、服务、数据表或另一个调度器。每个实际好友回复多两次本机 OneBot 好友列表读取（处理前和提交前），不发外部探测消息。

## 已有和本次验证的边界

- 主用户私聊仍走原绑定会话，其他好友没有主用户工具权限。
- 本次隔离回归覆盖不同好友、相同昵称、群聊/私聊、重开后的历史、好友停用、删除、连接中断、原件撤回以及检查期间的绑定/政策变化。
- 既有长期记忆回归覆盖真实 Native 写入/重开/召回、按账号及话题隔离、审核否决、更正/关闭/撤回来源、备份失败保护和安全撤销。回归中的审核大多使用固定结果，不代表真实模型语义质量。
- 真实好友验收指定 QQ 1415916725。用户提供账号表示测试对象，不将其添加为主用户；账号操作权限绑定保持原样。仅用真实、自愿保留的普通偏好做真实写入验收；不手工向生产库植入合成偏好。
- 用户控制该账号向 AI 发消息后，核对实时事件、模型提案、独立审核、来源版本和 Native 索引；再独立只读召回。近期上下文中的答复不能单独证明长期记忆召回。

所有好友原文及记忆数据仍在原实例 `runtime/dev`，迁移继续搬完整实例。不会因为删除好友就自动抹除既往交流；这属于另外的记忆删除/保留策略。
