# 社交经历提案的状态键格式

版本：companion-adapter 0.49.2。复用现有 QQ 桥接、调度器和全部数据库。

真实验收中，图片经历已完成评价并选择零变化。语音“雨崩徒步、自由”完成识别、群聊回复和调度选中后，成长提案因状态键不符合既有字符规则而失败，未进入独立审核，也没有写入自我或情绪。原失败任务保留，不自动重跑。

修复明确：interest/trait 的 key 最多 60 字符，只含文字、数字、空格、下划线和连字符，不带类型前缀、冒号、斜杠或标点；self_description/personal_prompt 固定用 current。

`social-experience-plan.js` 在同一冻结来源和状态版本下预检完整提案。只有键名字符和固定 current 键这两种语法问题，才允许同一模型纠正一次；程序不替模型改键、补提案或批准写入。纠正也可选择零变化。第二次仍失败则停止，错误引文、权限问题、网络错误、JSON 未完成等不走这个纠正通道。

每次模型调用都计入原成长共享额度，纠正前再次核验来源、身份和学习许可，受原总超时控制。首次和纠正后的提案及验证结果保留在原任务的 proposalAttempts 中；完整预检通过后才进入原有独立审核和有修改才备份流程。

此修复不重发消息、不重新识别语音、不生成指定情绪，不改变来源真实性要求或历史数据。真实语音产生并提交成长的分支仍需未来自然交流验收；不能以旧失败任务被保留或合成纠正测试通过冒充真实写入成功。
