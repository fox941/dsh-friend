# QQ场景回复、语音与原因展示

版本：companion-adapter 0.66.1 / qq-bridge 0.16.0。B站插件与调度插件保持原版本。

## 覆盖范围

好友、QQ群的文字/随图文字/待朗读正文；空间收件后自动形成的原评论回复；主用户工具生成的QQ语音及实际出站。主用户私聊文字继续使用0.65.1的本轮工具回执检查。

空间手动发布说说、手动根评论和其他账号操作仍走原有平台操作审核。B站未改动，后续与其开发窗口协调接入。这里不是所有自然语言事实的通用语义证明。

## 生成与提交

社交回调没有主用户私聊检索工具。原表达模型只读取原来的场景资料。宿主从本轮已载socialMemory条目提取限定引用，复核账号、范围、发言人、记录哈希与原发言。只有逐字存在于这些已获准读取文字中的引用，才支持本场景的文字匹配声明；不认证事件真实、科学结论、当前画像或在线重新读回。

有ID的后台任务声明没有本场景许可时保持未知，不为核实去查主用户私聊任务。即使群里发言者是主用户，也不自动把其私密库引入群聊。不同好友、不同群、空间可见范围的记录不能互相签发引用依据。

格式和事实问题共用原表达回调的一次纠正机会。仍由同一个模型选择回复、暂缓或忽略；不新加审核模型，不强制回应。事实纠正不能增加记忆或情绪提案，原提案保留给原独立审核。纠正后仍不符，保留草稿与失败原因，停止发出。

群/好友在媒体准备前、实际发送前分别检查。空间在提出回复候选前检查，并在平台操作实际写入前复核来源和正文；记录撤回、停用或可见范围不一致会阻止提交。正常媒体失败的既有文字回退保留；实际网络请求结果不明仍禁止自动重发。

## 语音

主用户语音工具在把正文交给TTS前检查本轮真实工具回执，随后把正文哈希和原用户事件引用放进现有语音资产元数据。实际发送时重新核对资产字节、正文、账号、原消息与任务当前状态。私聊引用凭据不能用来认证群或其他好友的语音。

普通旧语音仍可使用；旧资产若包含明确的核验通过声明却缺少可验证依据，会被阻止。Web发起或跨场景转送的语音不能借用QQ私聊核验凭据；当前缺少该来源重建能力时，涉及这些声明会保持未知/阻止提交，而不是假称通过。群/好友的正常语音直接使用本次场景证据，合成前和发送前各复核一次。

## 数据与界面

没有新表或记忆库。检查记录写入已有platform_meta，以qq-reply-check开头；其中保存来源引用、哈希、检查阶段及简短原因。原草稿、事件、媒体与平台操作继续保存在原来的位置，不改已有记忆正文或人格。

“记忆系统→自我与成长→活动与选择→QQ回复处理与未发送原因”展示最近24条处理记录。分别说明主动未回复、暂缓、核实未通过、尚为候选、已取得平台回执、发送结果不明。旧ignored若缺少模型选择依据，显示原因记录不足，不归因为情绪。展示不包含原聊天正文和凭据，也不增加一键重发或唤醒动作。

## 验证与限制

新增31项隔离测试覆盖好友/群隔离、工具调用误报、空间来源/可见范围、同一模型一次纠正、TTS前阻止、合成期间来源失效、发送前任务变化、真实语音资产接口、回退、结果不明禁止重发及页面只读展示。源码全量、安装包专项、数据保留和真实新消息验收结果由发布记录补充。

措辞识别仍有漏检及误拦的可能。状态核对是提交前快照，远端送达前可能变化。被阻止的草稿不会自动发送，可能表现为本轮未收到回复，原因可在页面查看。测试不会通过伪造主用户消息、写入人格、重开旧任务或向额外模型提交真实聊天来完成。
