# 自我状态与成长的只读页面

companion-adapter 0.54.0；现有QQ桥接、B站插件、注意力调度和记忆后端沿用。

入口：DSH → 记忆系统 → 自我与成长。原人物画像页面继续展示“她对主用户的了解”，本页展示“她自己的状态”。

## 四个栏目

- 当前感受：原情绪控制器的当前感受、较缓慢背景心境、已记录感受事项；程度、原因、审核把握和独立依据分别展示。
- 自我认识：自我描述、兴趣、性格认识和个人表达。区分暂定、较稳定、到期、撤回和依据待复核，可查看最近20版及来源。
- 变化与审核：原成长/情绪批次的提案、审核时旧值、逐字依据、审核结论及实际提交结果。审核接受不等于提交成功；重复依据或版本变化导致暂缓时显示实际回执。
- 经历与来源：近期QQ经历评价和B站活动，可查看关联、明确纠正、原始观察范围及后续审核。没有产生变化、选择不评价或原文没有进入成长事件表均如实标注，不补造经历。

## 读取和时间

每次打开或手动刷新从同一运行角色读取。情绪程度复用原控制器的时间投影，不写回强度、不刷新时效、不增加支持或触发反思。详情中的曲线是假定没有新事件时的工程投影，不能预测未来实际情绪，也不是心理测量。

当前自我列表最多80项，感受沿原控制器最多128项；近期各20条成长/情绪审核、各15条QQ经历/B站活动。状态历史和感受历史最多20版，正文有界且标记截断。页面不是全库档案，也不重新访问QQ/B站来证明原件仍存在。原件暂不可用与已删除不是同一回事。

## 通道与权限

复用现有已验证的Mnemon客户端页面扩展和DSH Connection Fetch载体；两个精确GET路由：/api/ai-friend-self-state、/api/ai-friend-self-state-detail。读取仅允许已鉴权owner浏览器，通过原共享载体阻止未登录和agent peer，保留原Gateway；详情类型和标识白名单校验。响应no-store，错误只显示通用说明。文字使用React文本节点，已识别凭据模式在截断前隐藏；不返回原始模型请求、认证配置或快照路径。

首版无状态修改按钮、写API、附加模型调用、新队列或新的存储。读取不改变记忆、人格、情绪、审核额度或召回次数。刷新失败保留上次结果并明确标注，不能当成刚刷新成功。

## 实现和迁移

self-state-view.js负责现有数据库与控制器的有界只读投影；self-state-host.js注册鉴权读取；client.js通过原模块加载器注册页面和React组件。只更新外部companion-adapter，不修改DSH、Mnemon、QQ桥接或B站源码。沿原插件版本和完整实例迁移，无新增角色数据目录或数据库表。
