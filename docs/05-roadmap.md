# 开发顺序与验收

更新：2026-10-27。第一步与第二步的基础运行链路已完成；已补充当前事实纠错、版本历史和运行能力适配。复杂中文语义和长期质量验收仍待继续。第三步的第一版自我状态、提案审核和依赖失效已实现，第四步的手动预演、可恢复应用与受控夜间整理均已实现；长期语义质量、身份跨平台绑定及夜间整理仍待继续。已完成内容见 [运行说明](06-running.md)，以下保留后续开发及验收顺序。

## 第一步：可重复启动的 DSH 开发实例

已准备项目专用 Node 24.22.1 和 pnpm 11.28.5，运行固定的 DSH 官方发布包，只启动本地 Web。显式设置 DSH_HOME 和 workspace，数据落在 runtime/dev；当前启动器只管理 dev，不会指向或替换 prod。

配置新的 DeepSeek 凭据，验证一轮对话、重启续接和受控工具调用。审查默认提示词及工具预设；个人描述不预填角色模板，不设置默认恋爱/性格，不运行无预算后台循环。

验收：本机 Node 版本匹配；启动/停止成功；实例没有写到默认用户 `.dsh` 或旧项目路径；无密钥进 Git；关闭浏览器后 Host 是否仍在运行可清楚判断。

## 第二步：验证现成记忆插件，而非马上重写引擎

在开发实例安装固定版 dsh-mnemon 和 Mnemon Native CLI，先关闭 Idle Review、技能自进化及无关组件；验证中文检索、语义改写、导出导入、卸载保留数据与其他后台调用。分别检查 DSH_HOME、Mnemon storageRoot、scope 和实际成本。

准备独立测试人格和资料集，不污染长期角色。dsh-ltm 作最简对照，Mneme 作自动整理对照，均用隔离实例；语义召回不足时比较嵌入方案和 Hindsight 等后端，不持续扩张自研检索引擎。

验收：候选兼容 rc.3；关键记忆可恢复；运行和迁移数据路径清楚；对复杂语义的不足有实测记录，不用单一命中率宣称全部解决。

## 第三步：外部陪伴插件的最小状态闭环

第一版已落地：空白 UUID 身份、自我状态、原话依据、语义审核、事务版本、依赖复核、自然语言情绪和重启连续性。当前仍是单一已鉴权本地主用户；QQ 身份绑定与 Mnemon 自定义 Source/Strategy 未完成，详见 [实现说明](08-growth.md)。

实现身份绑定、初始空自我状态、证据引用、变化提案和提交历史；优先使用 DSH 公开插件接口提供有界当轮状态，连接统一写入口与可恢复 outbox。验证默认记忆组合后，按实际缺口扩展 Mnemon 的 Source 或 Strategy；新增 Source 时检查它确实被所选 Strategy 使用，再完成真实状态变化和重启恢复。

以自然语言解释状态，可选数值只供宿主控制；不把聊天次数作为亲密增长函数。不让后台反思重复强化既有猜测。

验收：同一事件重放不重复改变状态；否决有理由；修正能使旧结论失效；普通个人提示词变化可自动生效，但无法扩大宿主权限。

|---|---|
| 反复强化 | 重复同一句、转发同一事件、夜间复述、召回自身摘要，不增加独立证据 |
| 语义误读 | 中文改写、否定、反讽、引用别人、假设与角色扮演，不能直接记成用户事实 |
| 矛盾与成长 | “以前喜欢、现在不喜欢”、条件偏好、主动纠错，保留时间和被替代关系 |
| 情绪数值割裂 | 同一语境换表达后，理由和状态不因关键词机械反转；不要求固定某一种感受 |
| 人格锁死 | 有新证据可修正自述；无新增证据的自我反思不自动成为更强锚点 |
| 召回偏置 | 冷历史能按需查到；单一主题不挤掉约定；其他联系人和群聊不串库 |
| 故障恢复 | 杀进程、网络失败、SQLite busy、部分成功后重启，没有静默丢失或无限重试 |
| 迁移 | 停写备份、新目录恢复、路径改变、schema 升级、版本回退与插件切换 |

语义类测试使用经过人工检查的中文资料集与保留的判断依据，不能只让同一个模型自问自判。记录召回、误记、冲突处理、来源完整性、调用成本和延迟；测试是工程行为评估，不是意识/情绪证明。
