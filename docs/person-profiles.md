# 统一人物画像与场景使用范围

版本：companion-adapter 0.42.2、qq-bridge 0.11.2、bilibili-tool 0.4.8。DSH、Mnemon、调度器与 NapCat 原生扩展不替换。

## 统一的是对人的认识

同一位主用户的 Web、已绑定 QQ 与已绑定 B站 UID 使用同一人物标识，来自原程序账号绑定；昵称、文字自称、群主身份、引用和转发都不能建立账号关联。其他 QQ 用户按真实 QQ 号识别，其他 B站用户按 UID 识别，不按同名跨平台关联。

画像是原记忆的有界只读视图，不另建一套事实库、不复制旧事实、不更改原会话或来源。原始 QQ 社交记录仍在 qq_social_*，原主用户资料仍由 Runtime/Native 管理，B站记忆仍由原审核应用和 Native 管理。原记录的更正、撤回、撤销和索引失效由原模块处理，视图每次读取时重新核对，不另存一套需要同步的画像副本。

## 适用与披露是两个条件

画像描述可附 `profile:{kind,scope,disclosure,authorizationQuote?}`，kind 为 address/habit/interest/preference，scope 为 person/scene，disclosure 为 source/public。

- person：关于同一个人的通用偏好；scene：只在原群、原私聊或原话题适用。限定本群、本次、这里、临时等原话不能升级为 person。
- source：保留原来源的披露范围。公开来源的通用偏好可以跨场景使用；群聊、好友可见空间及私聊来源不会自动带进其他公开场景。同一个人回到自己的私聊时，可以使用其通用偏好；不会把别人的资料给当前人。
- public：这条具体事实有明确公开使用授权。authorizationQuote 必须逐字包含本条 evidenceQuote 和无歧义授权，仍经过原独立审核。要求记住、绑定主人或允许跨会话不等于允许公开。

私聊来源获准公开的画像投影，只带已审核的事实，不把整段私聊引文、原群号或私聊线程一起提供给公开表达模型。公开身份识别不加载其他未获准私人资料。

场景约定优先于通用约定，当前原话优先于旧记录。不同内容仍保留各自来源和时点，不凭文本相似度自动合并、覆盖或判定哪条永久正确；冲突要按语境确认。画像不是 AI 自己的人格、兴趣或权限。

## 旧数据怎样使用

1. 原 QQ preference/interest 记录根据实际作者、原始完整发言和来源范围建立视图。原件有变化或原记录已撤回/撤销时不投影；公开自述中的通用偏好可直接在同一人的私聊、群聊或其他公开话题中使用。
2. 原 Runtime user 资料保持主用户私聊范围；没有可核对来源的局部旧条目不自行改成全局画像。旧私人资料不会因升级获得公开许可。
3. 新主用户记忆写入可附画像描述，描述保存在原申请和审核材料中；只有原步骤实际应用、当前记忆读回仍有效且没有撤销时，才进入画像。原样重复的无操作结果不会凭空创建新公开授权。
4. B站新记忆可附同样的描述。只从当前真实 UID 原话形成，经过原独立社交审核、实际 Native 写入和索引；旧的未分类社交经历不会整段自动当作人物画像。

不回放旧评论，不补写历史偏好，不修改原角色人格或情绪。只有读取方式改变，已有依据与记忆仍保留。

## 接入与预算

QQ 群聊、其他好友、空间表达在送入模型前获取过滤后的 personProfile。主用户 Web/QQ 私聊通过 DSH 公开的异步 system-prompt/assemble 钩子注入；未绑定、派生、种子会话不开放主用户画像。B站表达通过宿主 people 端口读取同一个视图，不引入 QQ 实现依赖。

`friend_person_profile_read` 是主用户私聊只读查看工具。原事实更正/撤回仍使用各自原入口；外部画像 ID 为只读引用，不能通过当前群或评论的提案直接覆盖其他范围的记忆。

每轮最多 12 项、6000 字符（包含条目元数据）；QQ 源最多 48 个候选、新主用户审核步骤最多 24 个候选、B站最多 16 个有类型索引。空间原件核对复用 3 条来源说说的上限与 historical-* 标记。统一视图读取最多 12 秒，父回合取消立即传播；可选画像暂不可用不阻塞普通聊天。不额外调用模型做“画像整理”，不增加常驻进程或数据库表。

## 验证与现实边界

隔离测试覆盖同人跨场景、账号冒认、默认私密、公开授权、局部约定、不同人隔离、原件变动、撤回、更正、撤销、重启、B站双向画像、无保存、数量/字符预算和取消。

真实安装的 DSH/Cordis 验证异步上下文能与其他插件共存。官方 DeepSeek 使用合成资料验证：没有旧话题历史时可用过滤后的称呼画像、独立审核拒绝把“请记住”当公开授权、明确授权可通过、B站公开表达可使用同一人的允许画像。合成测试不进入正式记忆，不向平台发送。

真实账号中的跨平台表达和授权变更，还需正常使用或真人验收。模型可能选择沉默或暂缓，不为了通过测试强制回复。程序隔离和合成模型测试不代表所有自然语言歧义都已消除；不确定授权保守保留原范围，不自动扩权。

## QQ 入场回执竞态修正（0.42.2）

第二轮真人原件显示，空间画像在首次模型回答前已出现，模型正常完成并明确回答通用称呼无需重认。但 QQ 投递轮询在 DSH claim 输入、异步装配、落盘之间的空窗误将原输入标成缺少持久回执，后来的真实 user/message 因状态已中断而无法登记 turn，最终正文没有进入出站。

现在同一 agent 正在运行且仍在原回合超时内时，未落盘不立即判失败；只等待原投递，不重新 followup。超过原超时仍保留中断。另可结算最近一小时、同一绑定最新一条、仅因缺少回执被误中断的原请求：必须在真实原会话找到唯一原输入、可信 QQ 来源、匹配且正常完成的 turn/end，并在原超时内完成；没有后续消息、任何出站或回应计划，才恢复原回合结算。

恢复只使用原已生成正文，经原 finish/outbox/发送回执流程，不重新调用模型、不伪造收件、不直接标记发送成功。取消、沉默/延后计划、混入其他直接消息、发送结果未知、较旧或已被新消息取代的回答不会借此重发。qq_reply_events 记录 admission_reconciled 技术审计。新增十三项竞态和去重验证。
