# 连续视频理解与整片时间线

companion-adapter 0.71.1 / bilibili-tool 0.5.1。保留 DeepSeek、原人格、记忆引擎及统一注意力，没有增加另一个机器人或常驻观看调度器。

## 使用

可以自然告诉她：「请连续看这条视频，按前后内容理解；可以分批，先排队再告诉我编号。」原 `friend_bilibili_explore` 增加 `viewMode=continuous`；`sample` 保留原有自主跳看。她在自主选片时也可选择连续模式，不要求每条视频看完。

连续模式从当前分P的0秒起顺序处理，第一版最多支持单个分P六小时。其他分P仍是独立内容，不能把完成一个P说成完成整个合集。长片每批沿用当前窗口长度和最多3窗，完成一批就释放执行器，把后续交回同一注意力选择。可以继续、延期、停止；主人暂停后须明确恢复。不是排进队列就算已经看完。

用原 `friend_activity_status` 看 `continuousReadings`；`friend_activity_read(activityId=reading.id)` 看总进度、章节和原件批次，`timelineOffset` 每次翻12项。`friend_activity_control` 带真实 `readingId` 可按本轮主用户原话暂停、恢复或取消某项。QQ仍从原消息持久排队，原请求保持到整项结束才发布最终结果；每批不会各发一条QQ。

## 本次增加的理解能力

1. 按时间覆盖整片，区分已处理区间、未处理区间、语言缺口、画面缺口与时序解释缺口。跳到片尾不能算完整覆盖。
2. 连续模式每窗默认12张实际解码画面，可配置4–24张；普通抽样仍保持原设置。FFmpeg一次解码选定窗口，按真实PTS保留时间，不用fps滤镜生成的时钟冒充源帧时间。
3. 同一次视觉请求结合本段字幕／转写、按时间排序的图片与前文，分别返回逐帧可见内容和跨帧暂时解释。模型只选真实帧ID、语言片段ID；原文和时间由宿主补齐，避免模型抄错字幕或猜时间。
4. 下一批携带本次观看已取得的前文。整项结束后基于各批原件引用生成章节、整体暂时理解和未解问题，便于以后按观察ID回查。摘要属于派生理解，不自动成为新的独立经历或再次强化人格。

本次仍不直接把音视频流送进原生音视频模型。音轨用于原有本地ASR；语言识别可能错字。连续分段和更密图片依然是有损观察，不保证帧间动作、短暂事件、语气或配乐被理解。`rangeCoverageComplete`仅表示区间具有实际文字或画面来源，不等于逐帧完整理解。

## 资源与失败边界

- 每批继续使用原活动日额度、冷却、超时和最多16次模型调用；续看批次也占原活动份额，没有暗中取消额度或增加常驻循环。长片可跨日续看，完成时间由资源和她的选择共同决定。
- 连续模式图片理解默认每窗12张，图片token成本高于普通模式。共享结构化审核默认仍最多6张；仅时序感知显式允许最多24张，QQ等其他路径保持原边界。
- 原64MiB视频分段传输、24MiB音轨读取、持久画面证据额度和来源白名单继续有效。达到额度会保留已有原件，并报告未完成范围。
- 图片JSON格式错误，每窗最多一次对同一来源的格式纠正；整片总结最多一次格式纠正，均计入原模型调用上限。其他错误不无限重试。
- 某条可选时序解释不合规时，保留已通过逐帧校验的图片描述，记录时序缺口；不会因为一句字幕被模型改写而丢掉整批有效画面。
- 重启保留批次、当前执行、原件及检查点；已完成批次不重跑。CID或时长变化会停止混用旧版视频。取消不删除历史，已结束事项不自动复活。

## 记忆与迁移

新增一张操作进度表 `activity_video_readings`，位于原 `runtime/dev/companion/companion.sqlite`。保存根任务、各批原件ID与哈希、连续游标、状态、章节和派生总结；它不是第二套长期记忆或人格。

各批仍使用原观察、视频片段、帧附件、笔记及记忆审核路径。`learn=false`在续看中保持，只留操作回执和实际观察，不写Native、兴趣、情绪或新笔记。允许学习时，各批是否保存仍由原审核决定；整体总结不另行自动写入长期记忆。全部批次都实际保存，才可称整项记忆全部保存。

迁移仍是停机迁移完整实例和匹配插件。需保留 `companion.sqlite`、DSH附件及原记忆，不能只复制新进度表。没有新增外部服务密钥、模型依赖或第三方框架。

隔离测试覆盖区间并集、源类型缺口、实际FFmpeg时间、引用编号、跨批次、原额度、模型停止、主用户暂停取消、进程恢复、CID变化、原QQ请求关联及整体章节核验。真实视频联调只使用独立测试数据，不把合成资料算成真实观看，不向QQ/B站发送测试消息，不写正式角色。

## 实际部署验收

2026-11-05：0.71.1 / 0.5.1已部署。源码与实际安装包各646项相关回归通过（同一套用例，不相加），新增27项专项。真实B站BV17QpneuEW4第1P的200秒内容在隔离数据中按0–60、60–120、120–180、180–200秒处理，两批共48张不同的实际画面，最大采样间隔约5秒。四段均取得平台AI字幕和有效时序解释，整体章节通过来源校验；实际8次模型请求含一次失败及同源JSON纠正，7次成功。不是人工证明每个语义结论正确，也不声称逐帧或声音理解。

最初的引用改写失败、文字完成但部分画面或时序缺失的中间报告均保留，未改写成成功。最终源码与安装包通过同一套回归，QQ桥和调度插件字节保持原基线；安装前完整停机快照已验证，原记忆／人格与收藏图库安装前后保持一致。正式角色没有被植入测试素材，没有发送平台测试消息。
