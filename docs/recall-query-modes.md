## 实现

沿用原friend_memory_recall和Mnemon公开工具链。首个query使用smart，alternateQuery使用已有keyword，模型仍决定是否检索和如何表达；第二表达建议少量核心主题/实体词，避免泛词堆叠，不写入猜测答案。每个请求不传alternateQuery时仍只查询一次；原标点/大小写等重复表达合并规则保留。

两次实际模式都传入原mnemon_recall，不是只改诊断标签。当前View、Source、ReadGrant、激活空间、父调用能力、取消和上下文信号继续由原链路检查。无法调用原工具时保留unavailable，不直接读数据库或放宽账号/场景权限。

修正自有vendored Strategy的缓存键，将mode与查询词、Source、空间集合一同纳入。原先相同词的keyword会误重放smart结果；现在两种模式是两次真实查询并分别计账，同词同模式仍复用原证据，不增加读取。普通每回合仍最多2次、8条，复杂理由仍最多4次、12条；正文共用12K字符，每项2K，普通中等相关每次1条、复杂每次4条均不变。没有提高额度、扩大候选包络或增加后台模型。

retrieval.calls显式记录query和mode。结果按原来源去重、正文变化冲突移除、保留逐字引文凭证及历史/外部标记；keyword评分也不等于语义正确，仍要求主模型判断是否回答原问题。未找到不表示全库没有，更正原件不作为当前偏好，视频观察不作为用户自述。
