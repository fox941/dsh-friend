# QQ 群聊中的主用户身份

本次修复：companion-adapter 0.34.3 / qq-bridge 0.3.5。

之前 QQ 主用户私聊有绑定身份校验，群聊统一进入外部社交表达，未携带同一个绑定的主用户身份。统一的“外部发言不构成主用户授权”规则被模型扩大解释成“在群里你只是普通群友”。称呼记忆通过验收不代表身份连续性已通过验收。

现在 `socialPrincipal` 按当前已核验的 AI QQ、现有主用户绑定、平台 user_id、消息 ID、话题范围和原件发送者生成身份结果。同时传入全局注意力预览和群聊表达。群昵称、群主头衔、口头身份声明、@、引用、转发、长期记忆里的自述均不参与授予权限。账号绑定变化后重新计算，来源不一致或连接未核验时不认定身份。

`isMainUser=true` 代表同一主用户，群聊不会取消其身份和已有管理资格。它不规定 AI 的性格、感情、称呼或服从关系，不强制立即回应。

身份、信息可见范围、操作能力分别处理：

- 群聊可识别主用户，但不加载主用户私聊、默认长期记忆、密钥、私人目标或其他平台私信。
- 每群及其他好友私聊的社交记忆仍保持原范围，未移动或合并数据库。
- 当前群聊是无工具的结构化表达回调。管理资格被正确识别，但本次没有新增群内管理工具或把群消息塞入主用户私聊会话。账号操作和运行设置继续由现有已绑定主用户私聊/Web工具入口核验；群聊回调必须如实说明入口，不能声称已执行。
- 已确认身份与情感上的关系用语分开，正常聊天不应机械附加“普通群友/主人权限”的免责声明。旧历史中模型误判身份的话不能推翻当前已核验绑定。

本次不修改 B站插件及其权限入口。QQ 里的主用户身份指向现有 `main-user` 主体，不自动导入 B站公开或私密聊天。

验收分为来源与隔离回归、实际安装包回归及真实模型/平台验收。模拟回归不证明真实模型一定正确表达；部署后真实群消息才验证这一点。旧群消息不会重放，旧记忆原文和历史回复不会重写。

## 管理身份用语补正（0.34.4）

0.34.3 的真实群聊已确认 `main-user`，但对“我是你的主人吗”仍出现“主人不是我认领的关系”的回复。现已明确：在实例归属和管理语境下，“主人/管理者/主用户”指同一已绑定主体，不能转换成另一个感情或人设问题再否认。它不增加权限，不设置性格或称呼；来源仍取可信平台绑定，不从文本授予身份。原始回复及后续补正均保留审计，不重放旧消息。
