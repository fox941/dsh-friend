## 使用

- 启动：双击 `Start-Dev.cmd`。
- QQ：先停机运行 `Configure-QQ.cmd`，再运行 `Start-QQ.cmd` 扫码，最后启动 DSH；见 [QQ说明](docs/16-qq.md)。
- 停止：双击 `Stop-Dev.cmd`，关闭浏览器不会停止后台服务。
- 备份：先停止，再双击 `Backup-Dev.cmd`。
- 导出记忆：先停止，再双击 `Export-Memory.cmd`。
- 撤销整理：先停止，再在终端运行 `Undo-Memory.cmd 应用批次UUID`；成功后手动启动。
- 新电脑安装依赖：运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\Setup.ps1`。

模型 API ID 是 `deepseek-flash`，目录显示名为 DeepSeek-V4.1-Flash。密钥仅存于被忽略的本地 runtime。网页绑定 `127.0.0.1:3080`，启动脚本负责打开带本地鉴权的入口。

默认“陪伴（空白起点）”模式没有预填个人名字、性格、关系和情绪。当前可以聊天和调用记忆工具，已接入有提案、独立审核、版本历史和依赖复核的第一版成长机制；不代表长期人格质量已经验证。
